# yt6video 稼働検証（2026-10-03）

## 結果
- stub台本 → スライド描画 → ffmpeg合成 → 連結 → 無音チェック → レポート：**6本すべて出力成功**
- 各MP4: h264 1280x720 30fps + aac / 尺 54〜62秒 / 無音スライド 0 / ナレーション網羅チェック 問題なし
- 日本語フォント（Noto Sans CJK）で文字化けなし、右上バッジあり、下部説明バーなし（EP0_contact_sheet.png）

## この検証環境で確認できなかったこと
- YouTube（タイトル・字幕取得）と edge-tts（speech.platform.bing.com）はクラウド環境のネットワーク方針で遮断（403）。
  → 文字起こしは sample_transcript.txt のフォールバック、音声はテスト用トーンに差し替えて検証。
  → 実音声・実字幕取得はPC上での実行で確認が必要。

## 修正した不具合
- `--out` に相対パスを渡すと、連結時に ffmpeg concat がパスを二重に解決して失敗していた。
  `core.run()` で出力先を絶対パス化して修正（yt6video/core.py）。
